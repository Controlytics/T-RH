1. Application Overview

What is RFID?

RFID (Radio Frequency Identification) uses radio waves to identify and track items. Unlike barcodes, RFID doesn't need line of sight — it works through boxes, packaging, and walls.

FeatureBarcodeRFID
Line of sightMust see barcodeWorks through boxes/walls
Speed1 item at a time100+ items at once
Range10-30 cm1-10 meters
DurabilityPaper gets dirty/tornChip works even if dirty
DataRead onlyRead AND Write
Unique IDCan be copied easilyTID cannot be copied

What does this app do?

Phone (Our App) ←── USB Cable ──→ RFID Reader ←── RF Waves ──→ RFID Tags (on items)
#FeatureDescription
1ConnectConnect phone to RFID reader via USB
2ScanDiscover and count all nearby RFID tags
3ReadRead data stored inside a tag's memory
4WriteWrite your own data to a tag
5Write EPCChange a tag's identity (EPC number)
6LockPassword-protect tag memory
7KillPermanently destroy a tag
8SettingsConfigure reader power, frequency, speed
9UKB ModeReader acts as USB keyboard
10ExportSave scanned data to CSV file

3. Feature: USB Connection

Purpose

Establishes communication between your phone and the RFID reader hardware through USB.

When to use

Every time you open the app. You must connect before using any other feature.

How to use

1 Plug RFID reader into phone via USB cable
2 Open the app (or it opens automatically when USB is plugged in)
3 Tap "Search Device" — App searches for the reader on USB
4 Status shows: "USB device found (VID:10473 PID:20993)"
5 Tap "Connect" — Phone asks "Allow USB access?" → Tap Allow
6 Status shows: "Connected successfully!" with beep sound
7 App automatically navigates to Scan screen

4. Feature: Tag Scanning (Inventory)

Purpose

Discover and count all RFID tags within range of the reader. The reader sends radio waves, and every tag in range responds with its unique ID.

When to use

SituationExample
Counting inventory"How many items are on this shelf?"
Finding items"Where is that laptop? Let me scan the room"
Receiving goods"Truck arrived, let me verify all packages"
Audit/verification"Does this room have all 50 expected items?"
Speed counting"How many tags pass through this gate per second?"

How to use

1 Make sure reader is connected (green icon on connect screen)
2 Tap "Scan" button → Button turns red, shows "Stop"
3 Move reader near items with RFID tags → Tags appear in list with beep
4 Tap "Stop" when done scanning
5 Review the list of scanned tags
6 Tap "Clear" to erase list and start fresh

Understanding the Stats

Stat CardMeaningExample
TagsNumber of unique tags found5 = five different tags detected
TotalTotal reads (same tag counted again)47 = reader detected tags 47 times total
SpeedTags read per second3/s = 3 tag reads every second

Understanding the Tag List

ColumnMeaningExample
EPCTag's unique ID (Electronic Product Code)E200A0B1C2D3
CountHow many times this tag was read12 = detected 12 times
RSSISignal strength (how close the tag is)85 = very close

RSSI Signal Strength Guide

RSSI RangeSignalDistanceUse
90-98🔴 Very Strong0-30 cmTag is touching/very close
80-89🟠 Strong30cm - 1mTag is very near
70-79🟡 Good1 - 3 metersTag is nearby

Tip: Finding a specific item
Start scanning and walk around. Watch the RSSI value of the target tag. RSSI getting higher = you're getting closer! When RSSI hits 90+, the item is right in front of you.

Tapping on a tag

When you tap any tag in the list, the app switches to the Read/Write tab with that tag's EPC auto-filled. You can then read, write, lock, or kill that specific tag.

5. Feature: Read Tag Data

Purpose

Reads data stored inside a specific RFID tag's memory. Every tag has 4 memory areas and you can read any of them.

When to use

SituationWhat to read
Check product infoRead User memory to see stored data
Verify authenticityRead TID (factory ID that cannot be faked)
Check tag identityRead EPC memory for full ID
Check passwordsRead Reserved memory
DebuggingRead any memory to check what's stored

How to use

1 Scan a tag and tap on it (or type EPC manually)
2 Select Memory Bank (Reserved / EPC / TID / User)
3 Set Word Ptr = starting position (usually 0)
4 Set Length = how many words to read (1 word = 4 hex chars)
5 Enter Access Password (default: 00000000)

6. Feature: Write Tag Data

Purpose

Stores your own data inside an RFID tag's memory.

When to use

SituationExample
Store product infoWrite batch number, expiry date
Assign assetWrite employee ID or department code
Set passwordsWrite kill/access passwords to Reserved memory
Update dataOverwrite old data with new information

How to use

1 Select the tag (scan and tap, or type EPC)
2 Select Memory Bank (usually User for custom data)
3 Set Word Ptr = 0
4 Enter Write Data in hexadecimal
5 Enter Password (00000000 if not locked)
6 Tap "Write"
Write Data Rules:
• Must be hexadecimal characters only (0-9, A-F)
• Length must be a multiple of 4 characters
• Valid: 48454C4C (8 chars) ✅
• Invalid: 4845E (5 chars) ❌
• Invalid: HELLO (not hex) ❌

7. Feature: Write EPC (Change Tag Identity)

Purpose

Changes a tag's EPC number — its identity. Like renaming the tag.

When to use

SituationExample
Assign your numberingReplace random factory EPC with your product code
Re-use tagsWrite new EPC for a different product
Organize inventoryEPCs with category prefix: "01" = electronics, "02" = clothing
Replace damaged tagCopy old tag's EPC to a new tag
⚠️ IMPORTANT: Only ONE tag should be near the reader when writing EPC! If multiple tags are present, the wrong tag might get changed.

How to use

1 Remove all other tags from the area
2 Place ONLY the target tag near the reader
3 Enter new EPC in Write Data field (hex, multiple of 4 chars)
4 Enter Password (00000000 if not locked)
5 Tap "Write EPC"

8. Feature: Lock Tag

Purpose

Protects tag memory with password so unauthorized people cannot read or change it.

When to use

SituationExample
Prevent tamperingLock EPC so no one can change the tag's identity
Protect dataLock User memory so stored data can't be modified
Secure passwordsLock Reserved memory so passwords can't be read
Anti-counterfeitLock everything so tag can't be cloned

Lock Memory Options

OptionWhat it locks
Kill Pwd (0)The kill password — prevents unauthorized killing
Access Pwd (1)The access password — prevents password changes
EPC (2)The EPC number — prevents identity changes
TID (3)The TID memory — usually already locked by factory
User (4)The user data — prevents data modification

Lock Type Options

TypeWhat it meansReversible?
No Protection (0)Anyone can read/write. Default state.N/A
Permanent R/W (1)Permanently open. Can never be locked.❌ No
Password Protected (2)Need password to access. Recommended option.✅ Yes
Permanent Lock (3)Permanently locked. Nobody can ever access.❌ No

How to use

1 Set access password first (if not already done):
Memory Bank = Reserved, Word Ptr = 2, Write Data = AABB1234 → Tap Write
2 Select Lock Memory (e.g., User)
3 Select Lock Type (e.g., Password Protected)
4 Enter Access Password = AABB1234
5 Tap "Lock"
⚠️ Permanent Lock (Type 3) cannot be undone! The memory area will be locked forever, even with the correct password.

9. Feature: Kill Tag

Purpose

Permanently and irreversibly destroys an RFID tag. After killing, the tag will never respond to any reader again.

When to use

SituationExample
Customer privacyKill tag after purchase so customer can't be tracked
Data destructionDestroy sensitive data on discarded items
Regulation complianceSome laws require tag destruction after use
DecommissioningItem is scrapped, tag should not exist
⚠️⚠️⚠️ KILL IS PERMANENT AND IRREVERSIBLE! ⚠️⚠️⚠️

Once killed, the tag becomes permanently dead. No reader in the world can communicate with it. There is NO undo. Make 100% sure before you kill!

How to use

1 Set kill password first:
Memory Bank = Reserved, Word Ptr = 0, Write Data = DEAD1234 → Tap Write
2 Enter Kill Password = DEAD1234 (same as what you wrote)
3 Tap red "Kill" button
4 "Kill successful" → Tag is permanently dead

Safety Features

Safety RuleWhat happens
Password = 00000000Kill is rejected (default password disabled for safety)
Wrong passwordKill is rejected
Must be 8 hex charsApp validates before sending command
Kill button is REDVisual warning of danger

11. Feature: UKB Mode (USB Keyboard)

Purpose

Makes the RFID reader act like a keyboard. When a tag is scanned, its EPC is automatically "typed" as text into whatever app is currently focused — Excel, Notepad, web forms, ERP systems, etc.

When to use

SituationExample
Excel data entryScan tags → EPCs fill cells automatically
Web form fillingScan tag → ID appears in form field
ERP/WMS systemsScan into any software with a text field
No custom app neededWorks with ANY app that accepts keyboard input

UKB Settings

SettingDescriptionDefault
Cut DataEnable/Disable trimming output dataDisable
AlignLeft or Right alignment (when Cut enabled)Left
Data OffsetSkip first N characters0
Data LengthHow many characters to output12
Output FormatHex (raw) or ASCII (text)Hex
Start CharacterText added before tag ID(empty)
End CharacterText added after tag ID(empty)
Add EnterPress Enter after each tagDisable
Byte IntervalDelay between each typed character3ms
Tag IntervalDelay between tags (×10ms)0

Setup for Excel

1 Go to UKB tab
2 Set: Add Enter = Enable, Filter Time = 500ms, Format = Hex
3 Tap "Save"
4 Go to Settings tab → Work Mode = UKB Mode → Tap "Set Work Mode"
5 Open Excel → Click on cell A1
6 Scan tags → EPCs appear in cells, one per row!
To return to normal mode: Settings tab → Work Mode = Answer Mode → Tap "Set Work Mode"

13. Understanding Tag Memory

Every RFID tag has a small chip with 4 memory areas:

┌──────────────────────────────────────────┐ │ RFID TAG CHIP │ │ │ │ ┌────────────┐ ┌────────────┐ │ │ │ Room 0 │ │ Room 1 │ │ │ │ RESERVED │ │ EPC │ │ │ │ Kill Pass │ │ Tag's ID │ │ │ │ Access Pass │ │ E200A0B1.. │ │ │ └────────────┘ └────────────┘ │ │ │ │ ┌────────────┐ ┌────────────┐ │ │ │ Room 2 │ │ Room 3 │ │ │ │ TID │ │ USER │ │ │ │ Factory ID │ │ Your data │ │ │ │ (read-only) │ │ (read/write)│ │ │ └────────────┘ └────────────┘ │ └──────────────────────────────────────────┘
Memory#ContentRead?Write?Size
Reserved0Kill & Access passwordsWith passwordYes8 bytes
EPC1Tag's ID numberAlwaysYes12-24 bytes
TID2Factory-unique serial (anti-counterfeit)AlwaysNever12-20 bytes
User3Your custom data storageYesYes0-512 bytes
Key Point: TID is the only memory that cannot be changed. It's burned at the factory and is unique to every tag in the world. This makes it ideal for anti-counterfeit verification.

14. Common Workflows

Workflow 1: Basic Inventory Counting

1 Connect reader
2 Settings: Power = 33, Session = S0, Q = 4
3 Scan tab → Tap "Scan"
4 Walk around with reader near items
5 Watch tag count increase
6 Tap "Stop" when done

Workflow 2: Find a Specific Item

1 Settings: Power = 20 (lower for closer range)
2 Scan tab → Tap "Scan"
3 Walk slowly, watch RSSI of target tag
4 RSSI increasing = getting closer!
5 RSSI 90+ = item is right here!

Workflow 3: Write Product Info to Tag

1 Scan → Tap on the tag
2 Read/Write: Memory Bank = User, Word Ptr = 0
3 Write Data = your hex data
4 Tap "Write"

Workflow 4: Verify Product is Genuine

1 Scan → Tap on the tag
2 Read/Write: Memory Bank = TID, Word Ptr = 0, Length = 6
3 Tap "Read"
4 Compare TID with manufacturer's database
5 Match = genuine. No match = counterfeit.

Workflow 5: Protect Tag Data

1 Write your data to User memory
2 Set access password: Reserved, Word Ptr = 2, Write = MYPASSWD
3 Lock: Memory = User, Type = Password Protected, Password = MYPASSWD
4 Now only you can read/write User memory!

Workflow 6: Scan Tags into Excel (UKB Mode)

1 UKB tab: Add Enter = Enable, Filter = 500ms → Save
2 Settings: Work Mode = UKB → Set Work Mode
3 Open Excel on phone/PC
4 Click cell A1
5 Scan tags → EPCs fill cells automatically!
